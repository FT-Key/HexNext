# US-005: Gestión de categorías

## Card Info
- **Trello Card**: [US-005: Gestión de categorías (M)](https://trello.com/c/tAEEkOaz)
- **Status**: In Progress
- **Phase**: P2 - Implement

## Description
Como **admin**, quiero **gestionar categorías** para **organizar el catálogo**

## Acceptance Criteria
- **AC-1**: ABM de categorías con jerarquía padre-hijo
- **AC-2**: Reordenar categorías (drag & drop o por orden numérico)
- **AC-3**: Al desactivar una categoría, sus productos quedan ocultos

## Plan
- **Core Layer:** Domain errors (`CategoryNotFoundError`, `CategorySlugNotAvailableError`), repository interface extended with `save()`, `findAllIncludingInactive()`, `findBySlugIncludingInactive()`
- **Use Cases:** `CreateCategoryUseCase`, `UpdateCategoryUseCase`, `ToggleCategoryActiveUseCase`, `GetAllCategoriesUseCase`, `ReorderCategoriesUseCase`
- **Validation:** `shared/validation/category-schema.ts` with Zod
- **Infrastructure:** `MockCategoryRepository` extended with write support
- **API Routes:** `GET/POST /api/admin/categorias`, `GET/PATCH/DELETE /api/admin/categorias/[id]`, `POST /api/admin/categorias/reordenar`
- **Components:** `AdminCategoryForm` (react-hook-form + Zod), `AdminCategoriesTable` (with edit/toggle)
- **Pages:** List, New, Edit under `/admin/categorias/`
- **Sidebar + Dashboard:** Updated with Categorías link and stats card

## Implementation
- Created `core/domain/errors/category-not-found-error.ts` and `category-slug-not-available-error.ts`
- Extended `ICategoryRepository` with `save()`, `findAllIncludingInactive()`, `findBySlugIncludingInactive()`
- Created 5 admin use cases: `create-category`, `update-category`, `toggle-category-active`, `get-all-categories`, `reorder-categories`
- Created `shared/validation/category-schema.ts` with Zod schema
- Extended `MockCategoryRepository` with write methods
- Created API routes: `categorias/route.ts`, `categorias/[id]/route.ts`, `categorias/reordenar/route.ts`
- Created `AdminCategoryForm` and `AdminCategoriesTable` components
- Created admin pages: list, new, edit
- Updated `AdminSidebar` with Categorías link
- Updated `AdminDashboardPage` with categories stats card
